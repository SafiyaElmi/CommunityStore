# CommunityStore

A web-based marketplace designed for students, vendor and residents to buy and sell products within the community.

## Features

* User registration and login
* Create and edit product listings
* Browse and search for products
* Place orders
* Product reviews and ratings
* Community bulletin posts
* Notifications
* Profile management
* Account deletion

## Technologies Used

* PHP
* MySQL
* HTML
* CSS
* JavaScript
* Bootstrap

## Project Overview

The platform provides users with a central place to list, discover and purchase products. It also includes community features that allow users to create posts, leave reviews and receive notifications.
